# Quality Management Artefacts

This directory contains version-controlled QMS artefacts for the Neomate 2 rebuild. It is a working baseline, not a claim of ISO 13485, IEC 62304, UKCA, CE, or regulatory compliance.

## Current Artefacts

- [software-development-plan.md](software-development-plan.md) - lifecycle and configuration-control baseline.
- [release-checklist.md](release-checklist.md) - minimum release evidence checklist.

## Required Before Clinical Deployment

- Approved intended purpose and regulatory classification assessment.
- Quality plan, supplier and dependency controls, and training records where applicable.
- Software safety classification, architecture, requirements, traceability, verification, and problem-resolution records.
- Clinical evaluation, usability engineering, cybersecurity, privacy, post-market surveillance, and release-management evidence appropriate to the deployed product.
- Formal approval by the responsible RCPCH governance roles.
