# `s/`

The `s/` directory contains small convenience scripts that standardise common development tasks.

## `s/lint`

Format-check and statically analyse the project.

## `s/test`

Run the complete Flutter test suite.

## `s/linux`

Launch the normal Flutter-native Linux application for local testing.

- `s/linux` - debug mode with hot reload
- `s/linux --release` - release mode

## `s/linux-driver`

Launch the development-only Linux entrypoint with Flutter Driver enabled for MCP interaction.

- `s/linux-driver` - debug mode with driver interaction and hot reload
