# Ubiquitous Language

| Term | Definition | Avoid |
| --- | --- | --- |
| Neomate 2 | This Flutter rebuild repository and its resulting application | “the app” where ambiguity matters |
| Clinical content | User-facing advice, references, checklists, doses, thresholds, warnings, and explanatory text | “static text” |
| Calculation | A deterministic transformation of stated inputs into an output, units, and explanatory result | “calculator” when referring to the code function |
| Clinical deployment | Use of a released build in a patient-care workflow | “production” without context |
| Source-derived vector | An independently reviewed input and expected output taken from an authoritative source or worked example | “test data” |
| Inherited behaviour | Behaviour found in legacy code before independent validation | “approved behaviour” |
| Safety-relevant change | A change that can affect clinical content, calculations, input validation, units, warnings, workflow, or deployment context | “minor change” |
